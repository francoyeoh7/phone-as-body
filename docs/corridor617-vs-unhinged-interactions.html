手势自动消歧短按、长按、拖动、取消、多指、页面失焦分别处理，不会把移动误判为互动指向 + 点击的二段式确认我们的额外能力同一块触控面同时承载移动和交互，界面更克制

断线安全断线、触摸取消、页面隐藏时发送更新序号的零输入；重新扫码可替换旧控制器官方资料只说明需要稳定网络工程优势避免断线后角色继续走动或继承陈旧输入
操作参数手机端提供体感灵敏度与视角平滑度并本地保存提供归中、提示、字幕和游戏模式等设置侧重点不同我们更关注传感器手感；对方更关注叙事可达性
手机拟真通信当前控制器未实现完整电话、短信、角色语音与来电 UI手机响铃、震动、播放电话语音并显示消息当前缺口这是《Unhinged》最鲜明的叙事优势
双屏音频导演尚未形成手机语音与电脑环境音的稳定分轨系统电话来自手机，环境声来自电视当前缺口需要独立的手机音频事件与同步策略
限时扫描 QTE已有任务和事件状态机，但当前不是以手机扫描热点 + 倒计时为主循环高压场景要求限时寻找正确物体当前缺口可作为自由探索之外的节奏强化层
手电筒手机入口协议保留 flashlight 动作，但当前手机界面没有可用的开关手势或按钮手电筒是核心体感表现需要补齐接入 UE 前必须明确开关方式和断线默认状态
机身轻拍/双扭手腕未完成：通用冲击检测没有接入实际操作，左右轻拍和双扭仅见于实验设计官方核心控制也不包含这些手势双方当前都无未来可成为真正区别于《Unhinged》的实体手势层

03. Corridor 617 的核心优势

一句话定位：不是“手机当遥控鼠标”，而是“手机表面 + 手机姿态共同组成一个无固定按键的双通道第一人称控制器”。

序号核心优势能力说明相对《Unhinged》的差异
01真正的自由探索玩家能连续前后移动、横移和转向，拥有传统第一人称游戏的空间自由。《Unhinged》主要在预设节点和热点之间推进。
02单面多手势复用同一个全屏区域通过时长和位移自动区分短按互动与长按拖动。不需要永久显示摇杆、互动键和一排虚拟按钮。
03双通道并行控制手指位移控制角色身体，手机姿态控制相机和光束，两者可以同时连续输入。表达能力高于只负责指向和点击的单一空中指针。
04体感离合降低漂移松手暂停姿态映射，允许玩家调整握姿；重新接触时以当前姿势重新校准。比始终工作的陀螺仪指针更适合长时间自由游玩。
05安装门槛低手机端是 HTTPS 网页，不要求下载专属 App；扫码即可进入房间。脱离 Netflix 生态，并支持控制器替换和断线恢复。
06可扩展到完整游戏输入协议与 Three.js/UE 游戏状态解耦，可继续增加手电筒、剧情电话、QTE 和实体手势。可以吸收《Unhinged》的叙事交互，同时保留自由移动。
事实口径：《Unhinged》交互依据 Netflix Tudum 官方介绍、 体感控制说明、 移动说明和 Story Mode 说明。 Corridor 617 交互依据当前 GitHub 主分支源码与自动化测试；旧设计文档中未落地的摄像头位移、双扭手腕和机身左右轻拍没有计入现状。
