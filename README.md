# Corridor 617

一个原创的手机体感恐怖游戏 Demo。电脑浏览器运行第一人称 3D 场景，手机扫描二维码后成为控制器：陀螺仪控制视线，整块手机屏幕长按拖动控制移动，后置摄像头检测从镜头前经过或持续停留的物体来触发交互。

## 体验内容

- 在停电的 617 号维护走廊寻找备用保险丝。
- 将保险丝装入配电箱并恢复走廊供电。
- 手机作为唯一操作区接管移动、视角和交互。
- 调查第三道门附近损坏的手机，松手即可退出资料界面。
- 在走廊尽头连续抵住安全门四秒；手离开后进度立即归零。
- 灯光、黑影和追逐事件会随目标推进。
- 完整流程可使用手机完成，约 5 到 10 分钟。

所有场景、剧情、程序化材质和合成音效均为本项目原创，不包含 Netflix 或其他游戏的品牌、角色、素材与剧情。

## 环境

- macOS、Windows 或 Linux
- Node.js 20 或更高版本
- 桌面端推荐 Chrome、Edge 或 Safari
- 手机端推荐 iPhone Safari 或 Android Chrome
- 手机体感需要 HTTPS 安全上下文
- 摄像头交互需要后置摄像头权限；画面只在手机本机低分辨率分析，不上传、不保存

当前 M4、16GB 内存的 MacBook Air 可以流畅运行该 Demo。项目使用浏览器技术而非 Unity，因此安装体积和启动成本更低，手机也不需要安装 App。

## 本地启动

```bash
npm install
npm run dev
```

电脑打开 [http://localhost:4174](http://localhost:4174)。本机键鼠测试可以直接使用 HTTP；真机方向传感器通常需要下面的 HTTPS 方式。

## 手机 HTTPS 连接

仓库不绑定特定隧道服务。以 Cloudflare Quick Tunnel 为例：

```bash
cloudflared tunnel --url http://localhost:4174 --no-autoupdate
```

命令会输出临时 `https://...trycloudflare.com` 地址。用该地址重启游戏服务器，让本地电脑页面生成安全的手机二维码：

```bash
PUBLIC_CONTROLLER_ORIGIN=https://你的临时地址.trycloudflare.com npm run dev
```

然后在电脑打开 `http://localhost:4174`，扫描页面二维码。也可以直接在电脑打开隧道地址。Quick Tunnel 地址每次启动可能变化，不适合正式发布。

## 手机操作

- 整块屏幕：长按并拖动，拖动方向控制角色移动。
- 同时转动手机：使用陀螺仪控制视角。
- 准星吸附到可交互物体后：让手或其他物体从后置摄像头前经过即可触发，普通交互间隔为 0.5 秒。
- 守门或查看拾获手机时：保持物体出现在摄像头前；移开后立即释放并重置当前持续交互。
- 短时间单击：摄像头不可用时的后备交互；长按拖动不会被误判为单击。
- 设置按钮：打开陀螺仪灵敏度、转向平滑度和重新校准方向。

iPhone 首次使用时，点击“允许并开始”，允许动作、方向与后置摄像头访问。切到其他 App、旋转屏幕或手机休眠后，返回控制器并点击“继续”重新校准。iPhone Safari 通常不提供网页振动，守门冲击会自动改用屏幕闪动和短促音效。

## 键鼠后备

- `WASD`：移动
- 鼠标：点击画面锁定指针并控制视线
- `E`：交互
- `F`：开关手电筒
- `R`：回中
- `Space`：守门阶段按住/松开的开发后备输入
- `Escape`：暂停或继续

## 常见问题

**手机显示“需要安全连接”**

确认手机地址以 `https://` 开头。局域网 `http://192.168...` 页面通常不能读取方向传感器。

**手机没有弹出体感或摄像头权限**

使用 Safari 或 Chrome 直接打开控制器，不要使用二维码 App 内置网页。刷新页面后再次点击“允许并开始”，并检查浏览器对动作、方向传感器和摄像头的权限。

**手机断线后角色仍在移动**

正常实现会在控制器断线、页面隐藏或触摸取消时立即把移动归零。若画面显示重连层，重新扫描当前二维码即可替换旧控制器并继续。

**画面太暗或容易晕**

使用手机暂停菜单调整体感灵敏度和稳定强度；可以开启准星、字幕与减少动态效果。键盘 `F` 或手机手电筒按钮可恢复照明。

## 技术结构

- Three.js：3D 场景、程序化材质、灯光和渲染
- Rapier 3D：玩家胶囊与走廊碰撞
- Socket.IO：电脑与手机房间配对和低延迟输入转发
- Device Orientation API：手机方向采样
- Web Audio：环境声、脚步、电流、惊吓、门锁与守门反馈音效
- Vitest：纯逻辑与流程测试

服务器只转发输入与布尔交互状态，游戏状态由电脑端维护。摄像头帧不会离开手机，手机传感器数据也不会写入磁盘。
