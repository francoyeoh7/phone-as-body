# Poly Haven PBR materials

Both material sets are distributed under Poly Haven's CC0 license.

- `rough-pine-door/`: Rough Pine Door by Dimitrios Savva.
  Source: https://polyhaven.com/a/rough_pine_door
- `forest-ground-01/`: Forest Ground 01 by Rob Tuytel.
  Source: https://polyhaven.com/a/forrest_ground_01

The runtime bundle uses the 1K JPG diffuse, OpenGL normal, and roughness maps.
